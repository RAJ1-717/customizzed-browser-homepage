# Google Homepage Clone

This project is a visual layout clone of the Google homepage built with HTML5 and CSS3 as part of Week 1 Mentorship Assignment.

## Project Structure
- `index.html`: The HTML document covering standard semantic sections like header, main search flow, and footer.
- `styles.css`: The stylesheet handling responsive spacing, layout alignments, flex layouts, and color variables.
- `assets/`: Folder dedicated to keeping theme assets (like custom logo graphics).

## Layout Approach
- **Flexbox Layout**: Used extensively to center the main content vertically and horizontally, and to space out header and footer links.
- **Responsive Adaptations**: The footer layout shifts automatically into a flexible stacked layout on compact tablet/mobile device dimensions.

## Features Met
- Top navigation flow with basic content links.
- Centered graphic element acting as the core placeholder.
- Rounded unified search segment containing vector-based icon guides.
- Dual actionable button tags situated right below the input section.
- Split footer structures aligning perfectly across broad screens.
